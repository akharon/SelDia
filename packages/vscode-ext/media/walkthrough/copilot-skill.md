## Enable Copilot Integration

Deploy the SelDiA DSL skill to teach GitHub Copilot how to write SelDiA diagrams.

### What Copilot can do:
- **Generate** diagrams from natural language descriptions
- **Suggest** the right diagram type for your scenario
- **Auto-complete** SelDiA DSL code inline
- **Convert** between diagram types (e.g., flowchart → sequence)
- **Explain** and refactor existing diagrams

### How to deploy:
1. Run **`SelDiA: Deploy Copilot Skill`** from the command palette
2. Choose deployment scope:
   - **Workspace** — Team-shared, version-controlled in `.github/skills/`
   - **All Workspaces** — Personal, roams with Settings Sync
3. That's it! Copilot now understands SelDiA DSL.

### Check status:
Run **`SelDiA: Check Skill Status`** to see if the skill is deployed.
