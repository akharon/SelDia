# Diagram Types

SelDiA supports **21 diagram types** across 8 categories:

## Structural
| Type | Description |
|------|-------------|
| [Class](/diagrams/class) | UML class diagrams with fields, methods, and relationships |
| [ER](/diagrams/er) | Entity-Relationship diagrams for data modeling |
| [Component](/diagrams/component) | Software component architecture |
| [Deployment](/diagrams/component) | Physical deployment topology |

## Behavioral
| Type | Description |
|------|-------------|
| [Sequence](/diagrams/sequence) | Interaction diagrams with lifelines |
| [State](/diagrams/state) | State machines and transitions |
| [Use Case](/diagrams/usecase) | Actor-system interactions |

## Architecture
| Type | Description |
|------|-------------|
| [C4 Context](/diagrams/c4-context) | System-level context view |
| [C4 Container](/diagrams/c4-container) | Container-level architecture |
| [Network](/diagrams/network) | Network topology |

## Flow & Process
| Type | Description |
|------|-------------|
| [Flowchart](/diagrams/flowchart) | Process flows and workflows |
| [BPMN](/diagrams/bpmn) | BPMN 2.0 process models |
| [DMN](/diagrams/dmn) | Decision tables |

## Data & Visualization
| Type | Description |
|------|-------------|
| [Bar Chart](/diagrams/chart-bar) | Bar and column charts |

## Project Management
| Type | Description |
|------|-------------|
| [Gantt](/diagrams/gantt) | Project timelines |
